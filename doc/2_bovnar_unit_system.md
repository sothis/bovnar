## Why this file exists

The IANA media type registration for `text/vnd.bovnar` cites this path as the
published unit system:

> <https://www.iana.org/assignments/media-types/text/vnd.bovnar>

A registration that has been published cannot be edited in place — correcting it
means submitting an update and waiting for Expert Review. Deleting this file
would leave that citation pointing at nothing in the meantime, so it stays until
the corrected registration is accepted.

The correction cites `https://www.bovnar.io/` paths rather than repository ones.
Those redirect across renames (the web server 301s every retired document path),
so the next renumbering will not break the registration again.

Nothing here is normative. Do not cite this file.
