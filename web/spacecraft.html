BOVNAR.bvnr / MISSION CONTROL — one format, config to downlink ← playground spec impressum

One format configures the spacecraft — and carries its telemetry home.

Every value on this page is real Bovnar, parsed live in your browser by bovnar_parser.js, a JavaScript reader for the format. Edit the config on the left to reshape the orbit; the simulator packs each measurement into a .bvnr downlink frame, and the visualizer runs purely on decoded values — never the raw simulation. Units, bit-widths and types ride inside the stream, so the ground station needs no schema to read it. Hover any gauge to jump to the line it decoded from.
